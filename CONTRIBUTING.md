# Contributing to Shelby Recovery Tool

This project is an early trial build — contributions and bug reports are welcome.

## Reporting a Bug
1. Check [Issues](../../issues) to see if it's already reported.
2. Open a new issue with:
   - Tool version (shown top-left, e.g. `v1.0.0`)
   - Device chipset/platform
   - Operation attempted (Flash, Read Back, Erase, etc.)
   - Scatter/DA/Auth files used (names, not full dumps)
   - Full log output from the **LOG** panel

## Suggesting a Feature
Open an issue tagged `enhancement` describing the use case, not just the feature.

## Pull Requests
1. Fork the repo and create a branch from `main`.
2. Keep changes scoped — one fix or feature per PR.
3. Describe what changed and why in the PR description.
4. Reference any related issue number.
